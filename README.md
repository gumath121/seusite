# Landing Page — Clínica Aurora

Primeira versão demonstrativa de uma landing page profissional para clínica.

## Arquivos
- index.html — estrutura da página
- style.css — visual e responsividade
- script.js — menu mobile, animações e rolagem suave
- assets/ — reservado para fotos/logotipo locais

## Personalização rápida
No `index.html`, troque:
- Nome da clínica
- Telefone/WhatsApp
- Endereço
- Horários
- Especialidades
- Nomes e registros dos profissionais
- Textos
- Fotos

As imagens atuais são demonstração e vêm do Unsplash.
